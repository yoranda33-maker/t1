WanderPlan - 해외 여행 플래너

실행 방법
1. 이 폴더 안의 index.html 파일을 더블클릭합니다.
2. Chrome, Edge 등 웹 브라우저에서 바로 실행됩니다.
3. 별도 서버, 설치, 빌드가 필요하지 않습니다.

파일
- index.html : 메인 화면
- styles.css : 디자인
- app.js : 모든 기능과 로컬 저장 로직

데이터 저장
- 입력한 내용은 브라우저의 localStorage에 저장됩니다.
- 같은 PC / 같은 브라우저에서 다시 index.html을 열면 유지됩니다.
- 브라우저 사이트 데이터를 삭제하면 저장 내용도 사라질 수 있습니다.

주의
- 외부 API를 호출하지 않으므로 실시간 항공권 가격, 환율, 지도, 날씨 정보는 포함하지 않았습니다.


비교 기능
- 여행 일정을 먼저 지정한 후 후보 여행지를 최대 4곳까지 비교할 수 있습니다.
- 각 여행지별 직항 항공권 Top5, 호텔/리조트 Top5, 현지 식비 예상가를 입력할 수 있습니다.
- 입력한 가격을 바탕으로 1인 기준 예상 총 여행비를 자동 계산합니다.
- 완전 오프라인 구조이므로 실시간 항공권/호텔/식당 가격은 자동 조회하지 않습니다.


v3 업데이트
- 동남아 여행지 대폭 추가:
  방콕, 푸켓, 치앙마이, 다낭, 나트랑, 하노이, 호치민, 발리,
  세부, 보라카이, 마닐라, 싱가포르, 쿠알라룸푸르, 코타키나발루,
  루앙프라방, 씨엠립.
- 향후 항공/숙박 API 연동을 위해 각 여행지에 IATA 도시/공항 코드를 추가했습니다.
- 여행지 탐색에서 동남아/동북아 필터를 사용할 수 있습니다.

실시간 가격 자동 조회 관련
- 대부분의 항공/숙박 API는 비밀 API Key 또는 Bearer Token이 필요합니다.
- index.html/app.js 안에 비밀키를 직접 넣으면 사용자 PC에서 그대로 노출됩니다.
- 안전한 자동 조회에는 API 키를 보관하는 작은 프록시 또는 서버리스 함수가 필요합니다.
